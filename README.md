# About Armless Suspect Helper
This (hopefully) will be a tool to help with evidence marking and such in the Roblox game _Armless Detective_. "But isn't that reductive because the game already includes the case file tool?" Sssssort of and also no but kinda. It's probably reductive if you're someone who can keep track of things mentally with relative ease, or if you see the current system as an intentional difficulty mechanic. If that's the case, that's cool, this project isn't necessarily for you. But I am very skill issue'd when it comes to memory and trusting my memory and regardless of whether it's supposed to be a difficulty thing, I am a simple guy! If a mechanic annoys me more than it feels like it challenges/engages me, I simply do not enjoy it! Yes i am skill issue'd and that is okay. peace and love on planet earth, etcetera etcetera.
